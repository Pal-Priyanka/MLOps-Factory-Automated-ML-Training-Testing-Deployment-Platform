# Dataset Guide & Placement Instructions

## 1. Dataset Overview

The project uses the enriched 50-column **IBM Telco Customer Churn** dataset (available publicly via Kaggle and IBM Developer communities). The dataset contains 7,043 subscriber records representing telecommunications service activity in California, Q3.

### Physical Characteristics:
- **Filename**: `telco.csv`
- **File Size**: ~1.93 MB (1,932,822 bytes)
- **Dimensions**: 7,043 rows × 50 columns
- **SHA-256 Provenance Fingerprint**: `f056d152686daf0706cebe7364ca8101a91cfeb08a0d0a525f0a2d216fe02901`

---

## 2. Placement Instructions

1. Place `telco.csv` in the root directory of this repository:
   ```
   Project-1-MLOps-Factory/
   ├── telco.csv
   ├── src/
   ├── tests/
   ...
   ```
2. The dataset is configured in `.gitignore` and `.dockerignore` to ensure raw personal or tabular data is **never** committed to version control or baked into container images.
3. If placing the file in a custom location, pass the `--data-path` argument to the runner script:
   ```bash
   python scripts/run_pipeline.py --data-path /custom/path/to/telco.csv
   ```

## 3. Column Schema & Data Types

The raw CSV contains 50 columns, categorized below into operational features and excluded leakage columns:

### 3.1 Operational Features (36 Columns)

#### Numeric Predictors (14):
1. `Age` (`int64`): Customer age in years (19 to 80).
2. `Number of Dependents` (`int64`): Count of financial dependents (0 to 9).
3. `Population` (`int64`): Population of customer's postal area.
4. `Number of Referrals` (`int64`): Number of friends referred to date (0 to 11).
5. `Tenure in Months` (`int64`): Duration of active subscription (1 to 72 months).
6. `Avg Monthly Long Distance Charges` (`float64`): Average long-distance fee.
7. `Avg Monthly GB Download` (`int64`): Monthly internet download volume (GB).
8. `Monthly Charge` (`float64`): Current monthly recurring bill ($18.25 to $118.75).
9. `Total Charges` (`float64`): Cumulative charges billed ($18.80 to $8,684.80).
10. `Total Refunds` (`float64`): Cumulative refunded credits.
11. `Total Extra Data Charges` (`int64`): Overage data fees ($0 to $150).
12. `Total Long Distance Charges` (`float64`): Cumulative long-distance fees.
13. `Total Revenue` (`float64`): Net revenue generated by customer.
14. `CLTV` (`int64`): Customer Lifetime Value calculated by actuarial index (2,003 to 6,500).

#### Categorical Predictors (22):
1. `Gender` (`str`): `Male`, `Female`.
2. `Under 30` (`str`): `Yes`, `No`.
3. `Senior Citizen` (`str`): `Yes`, `No`.
4. `Married` (`str`): `Yes`, `No`.
5. `Dependents` (`str`): `Yes`, `No`.
6. `Referred a Friend` (`str`): `Yes`, `No`.
7. `Offer` (`str`, 55.0% null -> imputed to `None`): `Offer A`, `Offer B`, `Offer C`, `Offer D`, `Offer E`, `None`.
8. `Phone Service` (`str`): `Yes`, `No`.
9. `Multiple Lines` (`str`): `Yes`, `No`.
10. `Internet Service` (`str`): `Yes`, `No`.
11. `Internet Type` (`str`, 21.7% null -> imputed to `None`): `Fiber Optic`, `DSL`, `Cable`, `None`.
12. `Online Security` (`str`): `Yes`, `No`.
13. `Online Backup` (`str`): `Yes`, `No`.
14. `Device Protection Plan` (`str`): `Yes`, `No`.
15. `Premium Tech Support` (`str`): `Yes`, `No`.
16. `Streaming TV` (`str`): `Yes`, `No`.
17. `Streaming Movies` (`str`): `Yes`, `No`.
18. `Streaming Music` (`str`): `Yes`, `No`.
19. `Unlimited Data` (`str`): `Yes`, `No`.
20. `Contract` (`str`): `Month-to-Month`, `One Year`, `Two Year`.
21. `Paperless Billing` (`str`): `Yes`, `No`.
22. `Payment Method` (`str`): `Bank Withdrawal`, `Credit Card`, `Mailed Check`.

---

### 3.2 Target Variable
- **`Churn Label`**: Binary ground-truth target (`Yes` -> Churned / 1, `No` -> Retained / 0).

---

### 3.3 Excluded Leakage & Identifier Columns (14 Columns)
- `Customer ID`: Primary key.
- `Country`, `State`, `Quarter`: Constants (`United States`, `California`, `Q3`).
- `City`, `Zip Code`, `Latitude`, `Longitude`: Spatial IDs with excessive cardinality.
- `Customer Status`: Target duplicate (`Stayed`, `Churned`, `Joined`).
- `Churn Category`: Explains churn reason; non-null exclusively for churned users.
- `Churn Reason`: Post-event exit interview text; non-null exclusively for churned users.
- `Churn Score`: Vendor predictive score (0-100) computed by IBM.
- `Satisfaction Score`: Exit survey rating (1-5); strictly separates churners.
